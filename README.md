# Publicação no GitHub Pages

1. Exclua os arquivos atuais do repositório.
2. Extraia este ZIP.
3. Envie todos os arquivos para a raiz do repositório.
4. Em Settings > Pages, escolha Deploy from a branch, main e /(root).

Senha ADM: 2580.

O rodízio troca automaticamente os quatro porteiros de posição a cada domingo. Exporte o JSON no modo ADM para manter uma cópia dos cadastros.
